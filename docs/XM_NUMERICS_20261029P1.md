# 2026-10-29：XM 剩余差异的因果验证

接续 [真实 UMX 采样末端修复](UMX_SAMPLE_GUARD_20261029.md)。两组 XM 的历史剩余差异已定位到原插件未初始化的采样前缀。原插件的插值器会使用这段内存；只在独立测试进程内将实际参与插值的三个前缀字节清零，两个文件的完整 PCM 均与当前重建版逐字节一致。

本轮没有发现需要继续修改生产混音算法的证据，因此保留 `2026.10.29` DLL，不为了文档和测试变更递增为 `p1`。重建版继续使用已清零的分配缓冲区，不复制旧插件的未初始化数据行为。

## 首个不确定状态在哪里产生

目标是原 `AddIn/ttp_mod.dll`，SHA-256 为 `e295817c9532d1a159a470b2caa6cb2dfc0bef7930f56d0d9ffacb05b1b8c036`。REA 6.5.0 CLI／Ghidra 12.1.3 的只读分析表明：

1. 原 `60453B0C` 按 `(nbytes + 39) & ~7` 分配内存，然后向调用者返回分配地址加 16。采样前面有 16 字节属于该分配的保护空间。
2. 分配入口 `6045558C` 最终调用 `malloc`，没有清零。采样读取填入音频主体，前面的空间保留先前堆内容。运行时直接在打开后的原 Reader 中观察到同一个文件的这段前缀随进程分配状态变化。
3. 原单声道 8 位 FIR 函数 `6046816A` 每个输出使用位置 `-3` 至 `+4` 的八个采样。播放位置处于采样开头时，`pSample[-3]`、`pSample[-2]`、`pSample[-1]` 参与整数插值；后续重新触发采样也会进入这一边界。
4. 当前固定版本 libmodplug 的 `AllocateSample` 使用 `GlobalAllocPtr(GHND, ...)`，同样返回地址加 16，但空间已清零。这是两者的确定性初始化差别。前缀不属于音频文件的采样内容，也不是应从文件还原的标签或音序状态。

最早的非确定输入因此来自采样分配后的前缀，而不是已经恢复的 FIR 系数表或最终 PCM 取整。当前两个用例在固定该输入后完整输出相同，足以解释本轮残差；不据此宣称所有格式的浮点路径在所有 CPU 上均相同。

| 原函数／证据 | REA Evidence ID |
| --- | --- |
| `60453B0C` 分配与 `+16` 返回 | `ev_d444cbc186359c951593c53d8faa73cf056d6a67c492e3d474d847900df2dd75` |
| `6045558C` 的 `malloc` 路径 | `ev_74a459f9013b8f4c4f16f018da2f934774ff1c8fadf3c8c101055c4614b093af` |
| `6046816A` 的八点读取与整数运算 | `ev_ac4d6588248018f09a3acb00bef610e0b7fa76931fb1ee1d6f55f29bbacd4e73` |

前两份完整证据是私有目录的 `original-allocate.json`、`original-allocator.json`；第三份沿用 `plugins_followup_20261025/mod/original-fir8.json`。地址与反编译结果是对指定二进制的观察，不是原厂源码。

## 三组独立进程对照

所有本轮探针、样本副本、PCM 与日志只保存于 `rebuild/tests/plugins_followup_20261029p1/mod`。`observe.cpp` 通过原工厂和 Reader 打开文件，再按已确认的对象布局读取采样槽；本探针仅接受这两个单声道 8 位 XM 用例，并验证布局及标志。

它记录浮点控制状态、每个采样 `[-8, -1]` 的自然前缀和末端保护区，然后采用以下模式之一，通过原 Reader 读取到 EOF，检查缓冲区哨兵和读取进度：

| 模式 | 唯一处理 | 运行次数 |
| --- | --- | ---: |
| 0，自然状态 | 不改采样内存，仅观察 | 每个文件 12 次，共 24 次 |
| 1，零前缀 | 在打开完成后、首次 Read 前，仅将每个有效采样的 `[-3, -1]` 三字节设为零 | 每个文件 12 次，共 24 次 |
| 2，固定非零前缀 | 同一三字节依次设为十进制 `31, 73, 127` | 每个文件 4 次，共 8 次 |

写入位置在已分配的 16 字节保护空间之内。未修改音频主体、末端保护区、音序状态、代码页、磁盘原 DLL 或生产重建 DLL。日志中的前缀在处理前打印，因而清零组日志也可能显示自然分配的非零数据。

结果与当前重建版完整 PCM 比较如下，差异数量按交错的 PCM16 值计数，而非按帧计数：

| 文件 | 自然状态不同值范围／最大差 | 零前缀不同值 | 固定非零前缀不同值／最大差 |
| --- | --- | ---: | --- |
| `finefx_ft2.xm`，274,432 字节 | 0–22／35 LSB | 每次均 **0** | 每次均 28／61 LSB |
| `ft2_double_toneporta.xm`，774,144 字节 | 675–1,713／458 LSB | 每次均 **0** | 每次均 2,086／758 LSB |

自然组分别产生 4 种和 7 种完整 PCM hash。零前缀组每个文件只有一种 hash，且等于重建版；固定非零组每个文件也只有一种 hash，尽管处理前的自然前缀仍变化。负输入／正输入两种受控结果连同静态读取路径构成因果证据，而不只是地址旁存在不同字节的相关性观察。

本机这些运行的 `_controlfp(0,0)` 均为 `0009001f`，MXCSR 均为 `00001fa0`。因此没有证据将当前差异归因于运行间改变的 FPU 控制设置；本测试没有穷举其它 FPU 模式。逐次输出及所有差异值保存在 `mode0-results.json`、`mode1-results.json`、`mode2-results.json`。

## 历史 22／1,227 个值及三个额外 1 LSB

`analyze.py` 将本轮控制结果与 `plugins_followup_20261024/legacy` 中保留的原版首次、原版重复运行和当前重建输出比较，生成 `causality.json`：

- 原历史参考与重建输出的差异数量仍分别为 22 和 1,227；这些差异位置全部包含在固定非零前缀产生的受影响位置集合内，没有集合外的历史差异。
- 两个历史原版运行之间分别有 22 和 1,306 个不同值。它们是两次自然堆状态之间的差异集合，不是所有可能受未初始化前缀影响位置的完整集合。
- 上一轮从第二组中单独留下的三个 1 LSB 值也位于受控前缀影响范围：

| PCM16 值的零基索引 | 历史原版 | 重建／零前缀 | 固定非零前缀 |
| ---: | ---: | ---: | ---: |
| 188,164 | -1 | 0 | -8 |
| 235,204 | -1 | 0 | -8 |
| 282,408 | -1 | 0 | -9 |

因此，这三个值不能再作为独立的确定性混音错误。它们此前落在两次自然运行差异掩码之外，原因是有限的自然运行没有覆盖完整的输入变化，而清零干预已经使整个文件一致。

## XP／Win7 复验与已有修复保护

平铺 `vmstage/run.cmd` 可在没有 Python 的 XP／Win7 上运行：每个 XM 进行一次自然观察，然后分别进行三次零前缀和三次固定非零前缀读取，使用系统 `fc /b` 对完整 PCM 做比较。自然前缀偶然全零是合法观察，不要求每次自然运行必须出现波动。

该 stage 有 **12 项受控比较、2 次自然观察**。Windows 11 本机、XP SP3 和 Win7 SP1 实际运行均为 `XM_CONTROLLED=12 NATURAL_OBSERVATIONS=2 FAILURES=0`，日志分别为 `vmstage-local.log`、`xp-result.log`、`win7-result.log`。三个系统的完整受控 PCM 均与相同参考逐字节一致。

本轮 XP 的处理前前缀恰好全零，Win7 的部分处理前前缀非零。这与分配状态影响前缀的解释相符，但不把某次系统运行的结果当作该系统永远返回零或非零内存的保证。测试没有因 XP 自然分配恰好为零而跳过固定非零干预。

`observe.exe` 为 x86、子系统 5.01，4 个导入 DLL、89 个导入符号通过 XP／Win7 清单审计，记录在 `observe-imports.json`。stage 的原 `original_mod.dll` 和 `msvcr110.dll` 只供私有对照；生产重建版没有增加 VC2012 依赖。文件 hash 清单保存在 `vm-manifest.json`，不将测试探针加入 Actions 或发行包。

本轮还使用未变化的最终生产 DLL 重跑已有核心验证，`core-final.log` 为 **17 个顶层组全部通过**，其中真实 UMX 的 63,188,992 字节完整输出仍为 FNV64 `d6eb225d4ea006b6`，独立原函数的 **864 项采样保护区比较全部相等**。八种格式、容量边界、Reader 并发、系数／抖动和定位隔离没有回退。
